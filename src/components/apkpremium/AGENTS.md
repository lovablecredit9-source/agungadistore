- APK PREMIUM (`/apk-premium`): browser -> edge `apk-premium` -> admin-configured JereAPI; features come only from `_shared/apk-premium-catalog.ts`, generated by `scripts/apk-premium/gen-catalog.mjs` from Jere-MD plugin source (WhatsApp-only/owner/spam/bypass/impersonation/fraud excluded; chat quiz games are included as one-shot question+answer, game endpoint = plugin file name), responses redacted. Then `scripts/apk-premium/merge-docs.mjs` merges the provider's official endpoint list (`jerexd-docs.json`): every documented endpoint must be a feature or an `APK_EXCLUDED` entry with a reason (test-enforced; harmless ones are re-allowed via `ALLOW` in merge-docs, and the catalog shows users every excluded path with its reason); doc-only features use the documented method (post=JSON body, paramsFile=FormData) and per-feature upload kind (`accept`). Why: the keys are the owner's paid credentials and the bot source is reference only.
- Provider keys live only in `apk_premium_keys` (AES-GCM, service-role only, masked last4 to the browser); every provider call goes through `withKeys` + `_shared/apk-premium-keys.ts` `runWithRotation`, using DB RPCs `apk_premium_pick_key` / `apk_premium_key_result`. Rotate only on provider quota/rate/invalid-key rejections, bounded attempts; never on 5xx/timeouts. Quota numbers come only from the provider (429 message, explicit daily-quota headers) or admin input — JereAPI `x-ratelimit-*` is a per-minute IP limiter and is ignored. Why: never repeat a possibly-run request or show invented quota. Legacy `apk_premium_provider.api_key_enc` is unused but kept.
- APK PREMIUM user actions (`run`, `me`, `yt_history_*`) require the Saldo wallet login via `resolveWalletIdentity`; YouTube history lives in `apk_youtube_history` (service-role only, no browser grants, keyed by wallet id, sanitized in `apk-premium/history.ts`: https only, no data:/credential links, media link only for successful conversions). Old device-local history is imported once per account and never deleted. APK PREMIUM has no tariff, so runs never touch balance. Why: history must follow the account and provider links are temporary.
- YouTube MP3 playback uses one app-wide audio element in `ytAudioStore.ts` (outside React), shown inline in APK PREMIUM and as `YtMiniPlayer` on every other tab; only the close button, account logout/switch, or starting a video stops it. Why: users want music to keep playing while browsing other tabs.

- APK PREMIUM (`/apk-premium`): browser -> edge `apk-premium` -> admin-configured JereAPI; features come only from `_shared/apk-premium-catalog.ts`, generated by `scripts/apk-premium/gen-catalog.mjs` from Jere-MD plugin source (WhatsApp-only/owner/spam/bypass/impersonation/fraud excluded; chat quiz games are included as one-shot question+answer, game endpoint = plugin file name), responses redacted. Why: the keys are the owner's paid credentials and the bot source is reference only.
- Provider keys live only in `apk_premium_keys` (AES-GCM, service-role only, masked last4 to the browser); every provider call goes through `withKeys` + `_shared/apk-premium-keys.ts` `runWithRotation`, using DB RPCs `apk_premium_pick_key` / `apk_premium_key_result`. Rotate only on provider quota/rate/invalid-key rejections, bounded attempts; never on 5xx/timeouts. Quota numbers come only from the provider (429 message, explicit daily-quota headers) or admin input — JereAPI `x-ratelimit-*` is a per-minute IP limiter and is ignored. Why: never repeat a possibly-run request or show invented quota. Legacy `apk_premium_provider.api_key_enc` is unused but kept.

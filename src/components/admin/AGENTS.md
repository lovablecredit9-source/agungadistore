- Admin layout lives in `src/components/admin/AdminShell.tsx` (sidebar/drawer/header/page header driven by `ADMIN_NAV`); `AdminDashboard.tsx` keeps all tab state and content. Global admin sizing rules are scoped under `.admin-ui` in `src/index.css`. Why: one admin, restyled without touching tab logic.
- New admins are added only via edge function `admin-accounts` (caller must be super_admin; creates the Auth user or reuses an existing one, refuses wallet-linked accounts, grants `user_roles` admin); admin login checks `has_role` before entering the dashboard. Why: passwords stay in Auth only and admins never become wallets.

# Music player & lyrics UI

- User lyrics UI (inline card, full player card, fullscreen) is one shared component `src/components/music/CinematicLyrics.tsx` that reads `audio.currentTime` per frame for active line/karaoke; styles are `.lyr-*` in `src/index.css`. Why: one renderer keeps every lyrics view in sync with the real audio clock.
- Music audio: volume/mute live only in PlaylistTab state (persisted via `src/lib/player-state.ts`); per-song audio listeners read `liveRef` (never closure state); `silenceOtherAudios` keeps exactly one audible element; true L/R balance is `fx.pan` on the StereoPanner, separate from the karaoke split (`fx.balance`). Why: stale closures and superseded loading songs caused overlap, stale repeat/shuffle and fake balance.
- Only `lyrics_review_status = "synced"` lyrics get the per-word karaoke sweep; other statuses render line-level highlight plus a "Waktu lirik perkiraan" label (`isTimingVerified` in `lyricsTiming.ts`). The player resolves the status from the full `playlist_songs` catalog because songs opened from Home/Artist/history carry partial rows. Why: unverified timestamps must never look perfectly synced.
- Lyrics status lives on `playlist_songs.lyrics_review_status`/`lyrics_verified_at`; validation rules are shared in `src/lib/lyrics-audit.ts` (client) and `validateLrcTimestamps` in `generate-lyrics-timestamps`, whose text-only fallback always returns `needs_review`. Synced requires admin Verify or an independent word-timestamp audio check (≥90% lines anchored, ≥70% words matched); Gemini full-song LRC times drift 10–25s, so never trust them as timing. Why: lyrics are never shown as Synced without audio evidence.
- Music Storage purchases go through `upgrade-storage` → service-role RPC `purchase_music_storage` (price/voucher from `storage_packages`/`music_discount_vouchers`, idempotent `purchase_ref`); Telegram `purchase` notice is sent after commit via `telegram-notify` (service-role only) and never rolls back. Why: client price/storage was trusted and quota lived in localStorage.

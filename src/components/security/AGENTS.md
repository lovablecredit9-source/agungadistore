- Login history: every insert goes through `insertLoginHistory` in `balance-auth` (IP from request headers via `_shared/login-device.ts`, structured device fields, `device_visitor_id`); reads only via owner-checked `login_history` / `security_summary` actions using `resolveWalletIdentity`, UI in `src/components/security/`. Why: the old action returned any account's history (with IP) for a browser-supplied id, and IP was client-supplied.
- Account switch / add account / logout end the previous wallet login session (`signOutWalletAuth`); "Logout Semua" revokes server sessions only via `signOutWalletAuthEverywhere` (scope global) for wallets linked to a login account. Why: a leftover session made the server resolve actions to the old account; legacy wallets have no server session to revoke.

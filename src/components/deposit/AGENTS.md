- Deposit UI is `src/components/deposit/PremiumDepositModal.tsx` (rules in `depositLogic.ts`) calling the existing `create-deposit`; inserts go through `create_deposit_atomic` (per-account lock, 30s dedupe) and the bonus rule lives only in DB `deposit_bonus_amount` (preview RPC `get_deposit_bonus_preview`, used by `admin_approve_deposit`). Why: the old preview promised a bonus the server never paid, and parallel clicks created several deposits.
- Payment proof: private bucket `deposit-proofs`, written/read only via edge function `deposit-proof` (owner upload while pending with magic-byte check; admin view via `isAdminRequest`); uploading never changes status or balance. Reject goes through admin-only `admin_reject_deposit` (pending-only, writes notification). Summary UI `DepositSummary.tsx` shows server preview only. Why: proof ≠ verification, and status changes must be atomic server-side.
